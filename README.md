# 프로젝트 시작 템플릿

개발을 처음 시작할 때 Codex와 대화만으로 기본 프로젝트 폴더를 만드는 템플릿입니다.

## 사용 방법

1. [START_PROJECT_PROMPT.md](START_PROJECT_PROMPT.md)를 엽니다.
2. 문서 안의 코드 블록 전체를 복사해 Codex 채팅에 붙여넣습니다.
3. Codex가 프로젝트를 만들 상위 폴더 경로, 프로젝트 이름, 프로젝트 목적을 **하나씩** 물으면 답합니다.

Codex는 이 저장소의 `boilerplate` 내용만 새 프로젝트 폴더에 복사하고, 프로젝트 이름과 목적에 맞게 Markdown 문서를 채웁니다. 이미 같은 이름의 폴더가 있으면 덮어쓰지 않고 다시 물어봅니다.

GitHub 업로드는 선택 사항입니다. 사용자가 원하고 GitHub CLI(`gh`)가 설치·로그인된 경우에만, 저장소 이름과 공개 여부를 확인한 뒤 최종 승인을 받아 올립니다. 키, 토큰, 비밀번호, `.env` 파일은 채팅이나 GitHub에 올리지 않습니다.

새 프로젝트에 들어가는 기본 파일 구조는 [boilerplate](boilerplate) 디렉터리에 있습니다.
